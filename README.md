# SQL-Restaurant-Project
This is my first SQL project where I have chosen a simple dataset to explore using different functions and skills I have learnt. The dataset comprises a menu item and order details table, I am also using SQL Server Management Studios.


The dataset includes a Menu Items and Order details table which are linked via the Item ID in the Orders table and the Menu Item ID in the Menu Item table. In the Order_details table it is composed of the following columns: order_details_id, order_id, order_date, order_time and item_id. Whilst the menu_items table has these columns: menu_item_id, item_name, category and price.


I have created hypothetical business questions in order to practice using SQL to garner useful insights within the dataset. By using SQL the Restaurant would be able to derive multiple insights. Firstly, they would be able to join the two tables together to clearly view their data as a whole. Another insight would be which nationality of food is most commonly sold along with which items are most ordered. Also, they could categorise the pricing of their items using a CASE statement to find how many of each item falls in each pricing group.
