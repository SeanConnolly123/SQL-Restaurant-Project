# SQL-Restaurant-Project
This is my first SQL project, where I’ve chosen a simple dataset to explore a range of SQL functions and querying techniques. The dataset consists of two tables — menu_items and order_details — and I am working with SQL Server Management Studio (SSMS). For this project, my focus is entirely on querying the data rather than cleaning it. The dataset contains several NULL values and inconsistent date formats, and addressing those issues will be the focus of my next project. For now, I wanted to concentrate on building confidence with SQL queries and understanding how to extract meaningful insights from raw data.

The two tables are linked through a shared identifier: item_id in the order_details table corresponds to menu_item_id in the menu_items table. The order_details table includes the following fields: order_details_id, order_id, order_date, order_time, and item_id. The menu_items table contains menu_item_id, item_name, category, and price.

Throughout this project, I’ve used a variety of SQL techniques — including subqueries, window functions, CASE statements, and aggregate functions — to explore the dataset and answer hypothetical business questions. Each query is designed not only to return results, but also to demonstrate why certain SQL features are useful in real analytical scenarios. For example, I used window functions to rank items by popularity, CASE statements to categorise menu items into pricing tiers, and joins to combine the two tables into a single, meaningful view of the restaurant’s data.

To guide the analysis, I created hypothetical business questions that a restaurant might ask. These include identifying the most popular cuisine category, determining which menu items are ordered most frequently, and analysing how items are distributed across different price tiers. By writing queries to answer these questions, I was able to practice applying SQL in a way that mirrors real‑world decision‑making. Insights from this dataset could help a restaurant understand customer preferences, evaluate pricing strategy, and identify opportunities to refine its menu or brand positioning.

This project serves as a foundation for future work, where I plan to incorporate data cleaning, more advanced SQL techniques, and potentially visualisation or reporting tools.
